# Generative_final_project

# Generative Virtual Multi-View HAR Baseline Pipeline

This project evaluates whether virtual multi-view skeletons generated from single-view 2D inputs can improve Human Action Recognition (HAR).

The pipeline performs 2D-to-3D lifting, azimuth rotation, virtual 2D re-projection, and downstream HAR ensemble inference using a frozen MotionBERT-based ActionNet backbone.

## Pipeline

HRNet 2D keypoints → MotionBERT 3D lifting → Azimuth rotation → Virtual 2D re-projection → ActionNet HAR inference → Late-fusion logit voting

## Repository Structure

```text
lifting_comparison/
├── generate_motionbert_baseline_pkls.py      # Generate lifted, rotated, and re-projected virtual-view pkl files
└── eval_motionbert_multiview_baseline.py     # Evaluate multi-view HAR with late-fusion logit averaging
```

## Method

The baseline consists of four main steps.

1. **3D Lifting**  
   Single-view HRNet 2D skeletons are lifted into 3D pose sequences using a MotionBERT-based lifting backbone.

2. **Azimuth Rotation**  
   The lifted 3D skeletons are rotated around the vertical axis using predefined virtual camera angles.

3. **2D Re-projection**  
   The rotated 3D skeletons are projected back into 2D coordinates and normalized into the format required by the downstream HAR model.

4. **Late-Fusion HAR Evaluation**  
   Each virtual view is passed through the frozen ActionNet HAR backbone. Final predictions are obtained by averaging logits across views.

## Dataset

The main input file is not included in this repository due to size.

| File | Description |

| `ntu60_hrnet.pkl` | NTU60 HRNet 2D keypoints for the `xsub_val` split |

The evaluation split contains 16,487 samples.

| Component | Description |

## Fusion Strategy

The baseline uses late-fusion logit averaging.

For each angle set, the HAR model produces one prediction logit per virtual view. The final prediction is computed by averaging the logits across all views and selecting the class with the highest averaged score.

Compared fusion target:

| Strategy | Description |
|---|---|
| Logit averaging | Average final classification logits from all virtual views |

## Usage

Navigate to the MotionBERT directory.

```bash
cd MotionBERT
```

Generate 3D-lifted, rotated, and 2D-reprojected evaluation datasets.

```bash
python generate_motionbert_baseline_pkls.py
```

Run multi-view late-fusion HAR evaluation.

```bash
CUDA_VISIBLE_DEVICES=1 python eval_motionbert_multiview_baseline.py
```

## Expected Output

The pipeline generates virtual-view `.pkl` files for each angle configuration and reports HAR accuracy for the frozen ActionNet backbone.

The main comparison target is the original single-view HRNet baseline.

## Notes

This baseline is designed to test whether virtual multi-view generation provides useful semantic information without retraining the downstream HAR backbone.

Potential limitations include domain gap from the 3D lifting model, viewpoint out-of-distribution effects, and noise amplification from simple logit averaging.
