# Virtual Multi-View HAR with cMAS

This project investigates whether virtual multi-view data generated by **cMAS** (a 2D→3D lifting diffusion model) improves **Human Action Recognition (HAR)** over single-view 2D skeletons.

**Pipeline:** HRNet 2D keypoints → cMAS (3D lifting) → azimuth rotation → 2D re-projection → MotionBERT (DSTformer) feature extraction → MLP classifier

---

## Repository Structure

This pipeline's own code lives under `hrnet/`. The cMAS and MotionBERT model
code is **not** duplicated here — it is shared from `../models/cMAS` and
`../models/MotionBERT` (see [Shared Models](#shared-models) below) and is
pulled in via relative-path `sys.path` insertion at the top of each script.

```
final_project/
├── models/                      # Shared model code (used by hrnet/ and kinect/)
│   ├── cMAS/                    # c-MAS diffusion model (model/, diffusion/, sample/, utils/, data_loaders/)
│   └── MotionBERT/               # MotionBERT backbone (lib/, configs/, save/ checkpoints)
│
└── hrnet/
    ├── cmas_pipeline/               # Step 1–3: generate virtual multi-view data
    │   ├── extract_ntu60.py         # Convert NTU HRNet pkl → NBA16 .npy per sample
    │   ├── run_cmas_batch.py        # Run cMAS diffusion model (../../models/cMAS) to lift 2D→3D
    │   └── rotation_projection.py  # Rotate 3D poses and project back to 2D
    │
    └── motionbert_har/              # Step 4–6: feature extraction and HAR training
        ├── lib/data/
        │   └── dataset_multiview.py         # Dataset classes for all view configurations
        │                                     # (extends the shared MotionBERT lib.data namespace)
        ├── extract_mixed_features.py        # Extract DSTformer features (../../models/MotionBERT) → .npz
        ├── extract_gt_val_features.py       # Extract GT-projected features for val subjects
        ├── train_singleview_mlp.py          # Baseline: single-view MLP (xsub standard split)
        ├── train_mixed_mlp.py               # Exp2: mixed GT-proj train → cMAS test
        ├── train_cmas_split_mlp.py          # Exp3: cMAS subject split (fair comparison)
        ├── train_view_attention_mlp.py      # Exp2 variant: view-attention fusion
        ├── eval_comprehensive.py            # Evaluate all experiments and print results table
        └── train_gt_split_exp.py            # GT-proj subject split (no domain gap ablation)
```

### Shared Models

`extract_mixed_features.py`, `extract_gt_val_features.py` and
`run_cmas_batch.py` resolve the model code relative to their own file
location:

```python
_MB_ROOT  = os.path.normpath(os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', '..', 'models', 'MotionBERT'))
sys.path.insert(0, _MB_ROOT)   # makes `from lib.xxx import ...` resolve to ../../models/MotionBERT/lib
```

Default checkpoint/config arguments (`--config`, `--backbone_ckpt`, c-MAS
`model_path`) likewise default to paths under `../../models/`, so the
scripts work out of the box as long as `final_project/models/MotionBERT`
and `final_project/models/cMAS` are populated (see their pretrained weights
under `models/MotionBERT/save/` and `models/cMAS/save/`, which are
git-ignored — download/copy them separately).

## Experiments

| Experiment | Train data | Test data | Key finding |
|------------|-----------|-----------|-------------|
| **Baseline** | HRNet SV (xsub) | HRNet SV (xsub) | 88.19% |
| **Exp1** | HRNet SV (xsub) | HRNet+cMAS MV (xsub) | MV hurts (domain gap) |
| **Exp2** | HRNet+GT proj MV (xsub) | HRNet+cMAS MV (xsub) | Feature concat: 85.85–86.07% |
| **Exp3** | cMAS MV (subject split) | cMAS MV (same split) | MV concat > SV (+0.04–+0.86%p) |

**Fusion strategies compared:** feature-avg, feature-concat, logit-avg

**Main finding:** Virtual multi-view consistently improves HAR when train/test distributions match (Exp3). Feature concat outperforms feature avg and logit avg across all angle sets.

## Usage

### 1. Generate virtual multi-view data

```bash
python cmas_pipeline/extract_ntu60.py       # NTU pkl → NBA16 npy
python cmas_pipeline/run_cmas_batch.py      # cMAS 3D lifting
python cmas_pipeline/rotation_projection.py # rotate + project to 2D
```

### 2. Extract DSTformer features

```bash
cd motionbert_har
python extract_mixed_features.py        # train (GT proj) + test (cMAS)
python extract_gt_val_features.py       # val with GT proj (ablation only)
```

### 3. Train and evaluate

```bash
python train_singleview_mlp.py          # single-view baseline
python train_mixed_mlp.py               # Exp2
python train_cmas_split_mlp.py          # Exp3 (main result)
python eval_comprehensive.py            # full results table
python train_gt_split_exp.py            # domain gap ablation
```
